# 幼兒園課綱活動對照

依領域與年齡查詢教育部《幼兒園教保活動課程大綱》的課程目標與學習指標，連到《幼兒園教保活動課程手冊》上下冊的實例與活動；也可以把自己設計的活動標注對應的學習指標，或從教學方法組成設計活動的提示詞。

- 在 Claude 裡開啟：直接由 Claude 標注指標、設計活動。
- 在其他地方開啟：網頁會複製提示詞，貼到 ChatGPT、Gemini 或 Claude，再把回答貼回網頁讀取結果；「關鍵字比對」不需 AI。
